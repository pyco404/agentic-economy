# Restore isometric controls and single-line citizen labels

Removed the experimental profile controller entirely: pointer interception, progress/target state, snap/release spring, camera interpolation, scene depth transform, profile-only foundation, backdrop/scenery fades, V shortcut and toolbar hint/button. Removed the experiment's implementation and tests without Git reset/restore. Existing city foundation/perimeter, architecture, roads, ambient actors, palette, water, backend state and UI are preserved.

The cause was the active profile controller: vertical gestures changed progress, while its frame update kept interpolating the camera and group transform toward the saved profile target after release. It also raised the camera's maximum polar angle. None of these paths remain. OrbitControls owns ordinary input again: left drag orbits, right drag pans, wheel zooms, one-finger touch pans and two-finger touch performs dolly/rotation. Polar limits remain 0.25–1.2 radians, comfortably above the horizon. Reset and Home restore the original (100,90,100) viewing direction and fitted overview zoom; only explicit inspection/home target easing remains.

The second agent-label line originated in `agentLabels.ts`: a `small` element populated from `identity.tag`. It and its CSS rule are removed. The label now contains one span with `identity.primary`, without status symbols, ID tags or duplicated wallet addresses. Label bounds use only that primary name. Selection/collision priority, outlined cream styling, canonical click targets and full inspector identity records remain intact. Legacy names remain stable; the backend handoff still applies for persisted globally unique house aliases and verified one-to-one activation records.

Review screenshots: `artifacts/profile-1440-after.png` shows the unwanted experiment before removal; `artifacts/isometric-restored-desktop.png` and `artifacts/isometric-restored-mobile.png` show the correction. These PNGs are ignored and are not committed. Browser coverage exercises all mouse-drag directions, pan/zoom cycles, reset angle, inactive V key, single-line label DOM, real touch pan/pinch and retained isometric limits against the local demo backend.
